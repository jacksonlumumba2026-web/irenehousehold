➕ How to Add a Product

1

Tap the ➕ Add tab

2

Tap Select photos — pick photos from your phone. Any filename is fine.

3

Fill in Product Name, Category, Price and Description

4

Type the Image Filename e.g. carpet.10

5

Select Badge and Stock Status

6

Tap 💾 Save Product to Website — photos upload and product goes live ✅

✏️ How to Edit a Product

1

Tap the ✏️ Edit tab

2

Type the product name to search e.g. Fluffy Carpet

3

Tap the product — form fills automatically

4

Change the price, name, description or any detail

5

Tap 💾 Save Changes — updates live immediately ✅

💡 To mark Out of Stock — Edit → select ❌ Out of Stock → Save. Shows red badge on website.

🗑️ How to Delete a Product

1

Tap the 🗑️ Delete tab

2

Search the product name

3

Tap the product — confirmation appears with photo and price

4

Tap 🗑️ Yes, Delete — removed from website immediately ✅

⚠️ Deletion is permanent. Use Edit → Out of Stock to hide temporarily instead.

🔑 GitHub Token Setup

One-time setup. Allows admin panel to save directly to website.

1

Go to github.com → log in

2

Profile picture → Settings

3

Scroll down → Developer settings

4

Personal access tokens → Tokens (classic)

5

Generate new token (classic) → tick repo → Generate

6

Copy the token immediately — it only shows once!

7

Tap ⚙️ Settings tab → paste token → Save Token ✅

🔒 Keep your token private. Never share it with anyone.
